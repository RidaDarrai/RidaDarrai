Subset (printable ASCII plus a few arrows and symbols) WOFF builds of the fonts
embedded into the cards by `scripts/render_readme_cards.py`:

| File | Family | Used for |
| --- | --- | --- |
| `serif-400.woff` | Lora | headings / large numbers |
| `serif-italic.woff` | Lora Italic | italic accents |
| `geist-400.woff` | Montserrat | heading 1, names |
| `geist-600.woff` | Montserrat SemiBold | bold labels |
| `body-400.woff` | Telex | body copy |
| `geistmono-400.woff` | Geist Mono | mono/kicker text |

The filenames are kept from the reference font set; the bytes inside
`geist-400.woff` and `geist-600.woff` are Montserrat, and `serif-*.woff` are Lora.
All faces are SIL OFL licensed.
